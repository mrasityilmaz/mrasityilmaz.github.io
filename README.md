# devrasityilmaz.com

Portfolio of Muhammed Raşit Yılmaz — Flutter developer, Istanbul.

Built with [Astro](https://astro.build), GSAP and Lenis. Deployed to GitHub Pages behind Cloudflare —
see [DEPLOY.md](DEPLOY.md) (in Turkish) for how publishing works.

```bash
npm install
npm run dev
```

Content lives in `src/data/` (apps, open source, site info) and images in `src/assets/`.
